OrbitLink - README

Overview
OrbitLink is a tool for Destiny 2 players designed to make joining fireteams easy and fast. With just a hotkey press or a click 
of a button, you can join fireteams directly from Discord by copying the Bungie ID or entering it manually. The tool also supports 
automatic joining attempts.

Features
- Hotkey Activation: Quickly join fireteams using customizable hotkeys.
- Auto Join: Automatically retries joining fireteams for up to 30 seconds at random intervals (0.5–1 second).
- Manual Join: Manually input a Bungie ID (e.g., Player#1234) to join a fireteam.
- Cancel Auto-Join: Use the ESC key to stop an ongoing auto-join session.
- History Logging: View past join attempts and successes in the history window.

System Requirements
- Operating System: Windows 10 or newer
- Available Storage: ~65 MB of free disk space
- Display Resolution: 1024x768 or higher
- Destiny 2 for PC running in “Windowed Fullscreen / Borderless”

- If Windows warns “Unknown publisher”, click “More info → Run anyway”. 


Guide on How to Use OrbitLink

1. Running OrbitLink:
   - After downloading OrbitLink, extract the folder somewhere and simply double-click the `orbitlink.exe` file 
   to launch the application. Make sure Destiny 2 is started and you're sitting in Orbit while running in “Windowed 
   Fullscreen / Borderless”.

2. Join a Fireteam Using Hotkey:
   - Copy a valid Bungie ID (e.g., Player#1234) from a LFG post, message or username from Discord.
   - Press the assigned hotkey (default is `F4`).
   - OrbitLink will automatically join the fireteam using the copied Bungie ID.

3. Manually Enter a Bungie ID:
   - Type the Bungie ID in the text field labeled "Enter Bungie ID (e.g. Player#1234)".
   - Click the "Join" button to manually join the fireteam.

4. Auto Join:
   - Click the "Auto Join (30s)" button to enable automatic joining retries for 30 seconds.
   - OrbitLink will attempt to join the fireteam every 0.5–1 second for the next 30 seconds.
   - You can cancel the auto-join process by pressing the `ESC` key.

5. History Log:
   - The "History" section shows past join attempts, with timestamps and results (success or failure).
   - You can filter through past join attempts using the search bar.

6. Minimise/closing:
   - Leave the window open, minimise it to hide it or click the "×" to fully close when you're done.
   - The ghost icon in the system tray means OrbitLink is still listening. Double click it to show Orbitlink again.


Troubleshooting

1. Destiny 2 Window Not Found:
   - Solution: Ensure that Destiny 2 is running and is not minimized, running in “Windowed Fullscreen / Borderless”.
   OrbitLink needs the game to be open and active.

2. Bungie Tag Not Found:
   - Solution: Ensure you've copied a valid Bungie ID in the format `Player#1234` from a Discord message, Username or LFG post.

4. Hotkey Not Responding:
   - Solution: Verify that the hotkey is not conflicting with other applications. You can change the hotkey in the settings.

5. History Log Not Updating:
   - Solution: Make sure the `join_history.log` file is in the same folder as OrbitLink. If missing, try restarting OrbitLink.
